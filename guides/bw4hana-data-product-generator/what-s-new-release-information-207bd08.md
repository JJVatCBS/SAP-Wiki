## What's New (Release Information)
The Data Product Generator for SAP Business Data Cloud is released via TCIs
(Transport-Based Correction Instructions) that you can implement into your BW system as a
SAP Note.

You can find more information on released features in the [What's New Viewer for SAP Business Warehouse](https://help.sap.com/whats-new/8a52c993cc40487dbb8d4f9492b8059b).
All new features and enhancements for the Data Product Generator for SAP Business Data
Cloud are marked with the product SAP BW in SAP Business Data Cloud
and the category Data Product Generator. New and changed features
which in addition have BW Modeling Tools listed as relevant
component require an upgrade to a new version of the BW Modeling Tools (BWMT) to become
available.

General information on new features in SAP Business Data Cloud can be found in the [What's New Viewer for SAP Business Data Cloud](https://help.sap.com/whats-new/31c53b47cac6482d89f167a1d2a4a50b) or [Road Map for SAP Business Data Cloud (SAP Road Map
Explorer)](https://roadmaps.sap.com/board?PRODUCT=73555000100800004851&range=CURRENT-LAST#Q3%202026).
