## Maintaining Data Subscriptions
The data subscriptions can be maintained in the Data Subscriptions app in the SAP
BW/4HANA Cockpit, in the RSDPS transaction in the SAP GUI, as well as in the Eclipse views
in the BW Modeling Tools.

You can create data subscriptions, create data subscriptions from template, edit data
subscriptions, activate and deactivate data subscriptions, and delete data
subscriptions.

In the BW Modeling Tools it's possible to mass generate data subscriptions based on BW
model, as well as mass delete, mass activate, and mass deactivate data subscriptions. In
the SAP GUI you can mass delete data subscriptions based on target.

For detailed procedures on these actions, see:

- [Creating Data Subscriptions](f2e950ed4e8c475b8571478d6c2004c0.html)

Note

On SAP BW 7.5 systems you need to use the RSPDS transaction in the SAP GUI instead of the
Data Subscriptions app in the SAP BW/4HANA Cockpit to maintain the data
subscriptions. The BWMT integration is available on SAP BW 7.5 and on SAP BW/4HANA
systems.
