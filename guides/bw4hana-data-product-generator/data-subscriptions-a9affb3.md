## Data Subscriptions
Data subscriptions are a new BW object type that have been introduced to support the
Data Product Generator in SAP BW and SAP BW/4HANA systems. For more information, see SAP
Note [3593519](https://me.sap.com/notes/3593519).

There are three ways to maintain the data subscriptions:

- [Data Subscriptions App in SAP BW/4HANA Cockpit](60146bc2b99941f2bdad39153fca5e9d.html) (SAP BW/4HANA 2021 and SAP
BW/HANA 2023 systems)

- [RSDPS Transaction in SAP GUI](67d73d2e2086409c8bc06ff79b116476.html) (SAP BW/4HANA 2021, SAP
BW/4HANA 2023 and SAP BW 7.5 systems)

- [BW Data Product Generator Perspective in BW Modeling Tools (BWMT)](21393d96c2f94fdebc20ee3941b4eb02.html) (SAP BW/4HANA 2021, SAP BW/4HANA 2023
and SAP BW 7.5 systems)

Note

On SAP BW 7.5 systems you need to use the RSPDS transaction in the SAP GUI instead of the
Data Subscriptions app in the SAP BW/4HANA Cockpit to maintain the data
subscriptions. The BWMT integration is available on SAP BW 7.5 and on SAP BW/4HANA
systems.
