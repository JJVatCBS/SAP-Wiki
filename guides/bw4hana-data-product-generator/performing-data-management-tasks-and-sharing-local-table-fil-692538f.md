## Performing Data Management Tasks and Sharing Local Table (File) to Other Spaces
You can work with the extracted BW data in the local table (file) after you shared it to
other spaces. In addition, you can perform data management tasks (such as deleting data)
directly in the read-only BW file space. If you access the Data Sharing Cockpit, you can
also create a data product out of your BW data.

### Prerequisites

- The BW administrator has set up and configured the Data Product Generator
for SAP Business Data Cloud. During the configuration, the BW
administrator has created a space to receive data pushed by the Data
Product Generator (BW file space). (For more information, see [Configuring the Data Product Generator](https://help.sap.com/docs/SAP_BW4HANA/ed919380760a44388ab90e6bb3e7480a/8586340e2bf647d783e4cf506559c25a.html?locale=en-US&state=DRAFT&version=1.0).)

- The BW administrator has created and run a data subscription to replicate
data from a BW InfoProvider into a local table (file) in the BW file space
in SAP Datasphere. (For more information, see [Creating Data Subscriptions](f2e950ed4e8c475b8571478d6c2004c0.html).)

### Usage of BW-generated Local Tables (File)

There are some specialties to consider when working with local tables (file) generated by
the Data Product Generator for SAP Business Data Cloud:

- The properties of the local table (file) and its structure cannot be changed
anymore.

- It's not possible to change settings for delta capture (OFF/ON) anymore. If
delta capture is OFF, delta capture changes won't be tracked and instead
historical snapshot versions will be kept.

- It's not possible to restore the local table (file) to a previous version.
You can only display the previous version.

- If partitions have been defined BW-side at table creation, you can see them,
but you can't change them or create new ones.
Note

Partitions can't be
maintained for the local table (file), but partition criteria from the
associated InfoProvider (e.g. DataStore object (DSO)) can be reused if
possible.

- Find and Replace is not available.

- The local table (file) in the BW file space is read-only (as all objects in this space are
read-only) - if you want to work with the data, you'll have to share it to
another space as a prerequisite.
Tip

If you delete the data subscription within your BW system, the local
table (file) becomes editable. For more information, see [Deleting Data
Subscriptions](51f2dd2a17a14a43ba265c537cce47ed.html).
In some situations, the local table (file) may remain locked after
the data subscription has been deleted - for example, due to a
connection error between the BW system and SAP Datasphere in SAP
Business Data Cloud at the time of deletion. If this occurs, you can
use the ABAP report
RSDDS_UNLOCK_LOCAL_TABLE
to unlock the local table (file) manually. For more information, see
[Unlocking
Local Tables (File) with Missing Data Subscription](ec61e47e062c41d68585343778350823.html).

### Performing Data Management Tasks for Local Table (File)

While the local table (file) and its data are read-only, you can still perform data
management tasks (such as deleting data) on objects in the BW file space.

The following data management tasks are available for your local table (file) in
addition to previewing its data:

- Viewing the Impact and Lineage Analysis diagram of the local table
(file): You can display the Impact and Lineage Analysis
diagram for the local table (file) to analyze its dependent objects (impact)
and its data origins (lineage). For more information, see [Impact and Lineage Analysis (SAP
Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/c8a54ee704e94e15926551293243fd1d/9da4892cb0e4427ab80ad8d89e6676b8.html).

- Monitoring the local table (file): You can monitor the local table
(file) to check how and when it was last updated and whether new data still
needs to be merged. For more information, see [Monitoring Local Tables (File) (SAP
Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/be5967d099974c69b77f4549425ca4c0/6b2d0073a8684ee6a59d6f47d00ec895.html).

- Exporting the local table (file): You can export the
local table (file) and its data to a CSN/JSON file. For more information,
see [Exporting Objects to a CSN/JSON File (SAP
Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/c8a54ee704e94e15926551293243fd1d/391610123f1f4a12abb12cbf77a3294d.html).

- Deleting data from the local table (file): You can
delete records from a local table (file) or versions of it to free up
storage space and for housekeeping. For more information, see [Deleting Local Table (File) Records (SAP
Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/c8a54ee704e94e15926551293243fd1d/6ec9b8a89dc64b5cac069cee81399c92.html) and [Deleting Data From Local Tables (File)
(SAP Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/be5967d099974c69b77f4549425ca4c0/872ad509995a451890bf8b80b73ec0e6.html).

### Sharing Local Table (File) to Other Spaces for Consumption in Models and Views

If you want to use the data in the local table (file) to create models and views, you first
need to share it to other spaces.

Users in these spaces can then discover and add the shared local table (file) to
their space. Once the object has been added to another space, it can be used to
create models and views just like any other objects in that space.

You can create models and views in the Data Builder or SQL Editor of SAP
Datasphere.Note

Sharing is only possible between spaces in the same SAP
Datasphere tenant. To be able to share the local table (file), you need a scoped
role with the privileges Data Warehouse Data Builder
(-R----S-) (to share objects to other
spaces) and Spaces Files (-R------) (to
access objects in the space). The DW Modeler role template, for example,
grants these privileges.

For more information, see [Sharing Entities and Task Chains to Other Spaces (SAP
Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/c8a54ee704e94e15926551293243fd1d/64b318f8afd74bb78467cf56eb44294f.html).

### Creating Data Product out of Local Table (File) in Data Sharing Cockpit

If you want to enable your extracted BW data for further use cases within SAP Business Data
Cloud, you can use the Data Sharing Cockpit in SAP Datasphere to create a data
product out of the local tables (file) in your BW file space.

The data products will appear in the catalog, accessible from both SAP Datasphere and the SAP
Business Data Cloud cockpit, and can be shared to SAP Databricks via Delta Sharing
where you can execute advanced AI (artificial intelligence) and ML (machine
learning) workflows on top of your BW data.

For more information, see [Data Provider's Guide - Data Sharing Cockpit (SAP
Datasphere)](https://help.sap.com/docs/SAP_DATASPHERE/e4059f908d16406492956e5dbcf142dc/e479b7b4c95741c7a7a1d42397984c7e.html) and [Creating Data Products (Data Sharing Cockpit)](b13c0b5d25eb4b658d5b76f60281e91c.html).
