# 3724724 – Data Subscriptions 4.0 for BW on HANA and BW/4HANA 2021 and 2023

Version 21 · freigegeben 07.10.2026 · Komponente BDC-BW · [in SAP for Me öffnen](https://me.sap.com/notes/3724724)

SAP Note

3724724 - Data Subscriptions 4.0 for BW on HANA and BW/4HANA 2021 and 2023
Component: BDC-BW (Business Data Cloud > SAP BW (PCE)), Version: 21, Released On: 07.10.2026

## Symptom

The current SAP BW or SAP BW/4HANA system does not support Data Subscriptions which can be used for the SAP BW
Data Product Generator (DPG) for SAP Business Data Cloud.
It replaces the former TCI notes 3593519 (TCI 2.0) and 3678407 (TCI 3.0).
With this note the Query Template Generator is introduced (QTG). The query template generator offers the possibility to
transfer a SAP BW query including info providers and info object to SAP Business Data Cloud. Currently not all features kown
in SAP BW are provided and due to the archtecture some features won't be supported at all. In order to check if the queries
are transferable execute the ABAP report "rsdwc_tg_check_queries" in advance. Additionally, please check
note 3774419 about supported features. This note will be updated regularly.

## Other Terms

BWonHANA, BW/4HANA, DPG

## Reason and Prerequisites

System Requirements
Systems for which the TCI is available:
SAP BW 7.50 system running on an SAP HANA database aka BW on HANA. The minimum support package is SP26.
SAP BW/4HANA system release 2021. The minimum support package is SP04. (Please note the new SAP_BASIS
requirements)
SAP BW/4HANA system release 2023. The minimum support package is SP04.
If you have already installed Data Subscriptions 2.0 and 2.1 or 3.0, Data Subscriptions 4.0 can still be installed on top.
In the future the SPs for subsequent corrections will have to be increased.
Unsupported Systems:
SAP BW/4HANA 1.0 and SAP BW/4HANA 2.0 are not supported.
Embedded SAP BW (releases > 7.50) is not supported. Refer to SAP Note 3584640 for important details.
Legal and Contractual Requirements
The use of the Data Product Generator is only allowed if there is a corresponding capacity service of SAP Business Warehouse,
private cloud edition within SAP Business Data Cloud (SAP BW, private cloud edition for SAP NetWeaver or SAP
BW/4HANA, private cloud edition). Refer to SAP Note 3590400 for important details and the SAP Business Data Cloud
Core Capacity Supplement.
Transport-Based Correction Instructions (TCIs)
Using the Data Product Generator may require the implementation of Transport-Based Correction Instructions (TCIs).
Implications on System Conversions and Upgrades
For SAP BW NetWeaver, the TCIs can only be applied to systems with software component SAP_BW 750. All higher releases
for SAP_BW are not supported. Embedded SAP BW is also not supported, regardless of the release.
Please nore, if the TCI for Data Product Generator is installed on a SAP BW NetWeaver 7.50 system, only the conversion
paths from SAP BW NetWeaver 7.50 (with TCI) to SAP BW/4HANA 2021 (SP05 or higher) and SAP BW/4HANA 2023 (SP04
or higher) are supported, otherwise the Data Product Generator functionality and corresponding custom metadata models
will be lost.
Planning the installation of the TCI 4.0 Data Product Generator
Please note that this correction will activate a new BW object type. Due to the central extension, many programs must be
recompiled, which is extremely runtime‑intensive. Because the recompilation starts whenever an affected program is touched,
the system may experience severe performance degradation for a certain period of time. It is therefore recommended to
implement the correction outside regular business hours (or to plan accordingly for the significantly increased system load).
After Installing the TCI 4.0 DPG, it is recommended to run SGEN ( FAQ TA SEGN - more Information please see note
1989778)
Prerequisites for Installation of TCIs for Data Product Generator

It is imperative, that you make sure that your note assistant (transaction SNOTE) is up to date before you
begin any installation, because there are recent corrections which would otherwise corrupt the TCI installation. There is
a button "Check Note Assistant" which guides you with that, alternatively, make sure that notes 1668882, 2869143 and
3093855 are installed in the latest version (these are collection notes which are regularly updated).
Make sure that your administration user is equipped with the roles SAP_OCS_STD and SAP_OCS_TCI_IMPORT
required to use the Support Package Manager (SPAM).
Implement the latest released patch level for the Support Package Manager (SPAM). The minimum patch level for SPAM
is 95.
To implement a TCI, transaction SNOTE in the ABAP system must be enabled for the same. Refer to the resources
below:
- SAP Note 2187425 - Information about SAP Note Transport based Correction Instructions (TCI) including the attached
PDF document
Download and apply SAP Note 1668882 to ensure that corrections for transaction SNOTE are applied to your system.
IMPORTANT: Ensure the latest version of the Note Assistant is installed
Please Check note 3093855 - Note Assistant: Important SAP Notes for the Revamped Note Assistant for completeness
Note: The TCI must be installed via transaction SNOTE ( SAP NOTE ASSISTANT). Do NOT use
transaction SPAM for this step.

Analyzer files for UI5-Corrections which are prerequisites for the TCI. Follow that note to implement the single required
UI5 notes, otherwise you will get a memory overflow during the TCI installation.
Update SPAM Version to min. Patch Level 95 (please check SAP Note: 2843922 - Error TK 566 when releasing a
workbench request, which contains Transport based Correction Instructions (TCI))
