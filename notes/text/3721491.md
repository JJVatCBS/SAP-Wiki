# 3721491 – Clarifications and Constraints on Integrating S/4HANA Cloud, Private

Version 2 · freigegeben 28.09.2026 · Komponente CA-JOULE-PRV · [in SAP for Me öffnen](https://me.sap.com/notes/3721491)

## Symptom

User need clarity on the following queries during Joule onboarding:
How to order Joule in a RISE S/4HANA Cloud Private Edition environment?
From which version of SAP S/4HANA Cloud, private edition Joule is supported?
Whether SAP S/4HANA on-premise systems can be enabled for Joule?
What is the minimum SAPUI5 version required per release for successful Joule features?
Which type of communication user should be used for backend connectivity during the Joule setup?

## Environment

Joule
SAP S/4 HANA Cloud, private edition
SAP BTP, Cloud Foundry runtime and environment

## Cause

This KBA is not related to Partner TDD installations.

## Resolution

1. How to order Joule in a RISE S/4HANA Cloud Private Edition environment?
For new greenfield RISE customers, Joule Entitlements are enabled by default.
For existing RISE customers, you need to meet the pre-requisites regarding release versions and you must order
this via your SAP Account Executive.
Refer to SAP Blog Joule for SAP S/4HANA Cloud Private Edition - A Comprehensive Setup Guide -> "How do I get
access to Joule?", for more details.
2. Joule is available for SAP S/4 HANA Cloud Private Edition 2021 onwards but with some exceptions.
All capabilities of Joule may not be supported from 2021 but from a higher release.
For the list of capabilities available per release of SAP S/4 HANA Cloud Private Edition, refer to Release-Specific
Capabilities and SAP Note 3523238 Navigational and Transactional capabilities with Joule in SAP S/4HANA Cloud
Private Edition.
3. Joule is available for SAP S/4HANA Cloud Private Edition only within RISE with SAP and in an SAP managed data
center setup, but not all on-premise environment.
4. The communication user must be created as a "Communication" user type.
5. To be able to use the Joule capabilities, the minimum UI5 version required per release of the SAP S/4HANA Cloud
Private Edition system must be used, as given in the following table.
