# 3255746 – Unpermitted usage of ODP Data Replication APIs

Version 12 · freigegeben 09.06.2026 · Komponente BC-BW-ODP · [in SAP for Me öffnen](https://me.sap.com/notes/3255746)

SAP Note

3255746 - Unpermitted usage of ODP Data Replication APIs
Component: BC-BW-ODP (Basis Components > BW Service API > Operational Data Provisioning (ODP) and
Delta Queue (ODQ)), Version: 12, Released On: 09.06.2026

## Symptom

The Remote Function Call (RFC) modules of the Operational Data Provisioning Data Replication API (ODP-RFC) are
intended and designed exclusively for facilitating data transfer between SAP applications. Any use of ODP-RFC by customer
or third-party applications to access SAP ABAP applications that contain one of the following components (PI_BASIS, SAP
BW, SAP BW/4HANA) that run on-premise or in private-cloud setup is prohibited. Due to security concerns, arising
from customer or third-party applications improperly using ODP-RFC, SAP is launching a comprehensive security
enhancement initiative. This effort comprises the release of SAP Note 3439624, which provides automated
assessment tooling via a self-assessment utility to audit existing ODP-RFC usage across customer environments, as well as
a new Security Note 3748819 (June 2026 Patch Day) delivering a technical update that validates incoming calls against
available subscriber types and blocks unpermitted ODP-RFC calls. Customers are advised to promptly install these notes.
SAP reserves the right to modify ODP-RFC modules at any time without prior notification to customers.
Any issues or incidents resulting from ODP-RFC implementation outside the scope of SAP’s prescribed guidelines remain the
sole responsibility of the customer.

## Other Terms

ODQ, ABAP CDS, @Analytics.dataExtraction.enabled, extractor, DataSource, S-API

## Solution

Customers may explore alternatives for transfer of data to third-party applications as described in the Documentation, some
of which include:
SAP Business Data Cloud (BDC)
ODP OData API (ODP OData)
To install the Self-Assessment tool, install the Note: 3439624 - Self-Assessment for data access to ODP Data Replication
APIs.
In case of any open questions regarding ODP-RFC, please reach out to your SAP contact person.
More information on ODP-RFC is available in the FAQ.
