# 3759180 – SAP BDC Capacity Units FAQ

Version 1 · freigegeben 30.06.2026 · Komponente BDC-PROV · [in SAP for Me öffnen](https://me.sap.com/notes/3759180)

SAP Knowledge Base Article

3759180 - SAP BDC Capacity Units FAQ
Component: BDC-PROV (Business Data Cloud > Landing component for BDC Provisioning (DSP, SAC, BDC)),
Version: 1, Released On: 30.06.2026

## Symptom

After Capacity Units (CUs) of SAP Business Data Cloud (BDC) are purchased, there are questions about how CU is
defined, allocated, monitored, and managed in SAP Business Data Cloud and across the core components such as SAP
Datasphere, SAP Analytics Cloud, and SAP Databricks.
This is a Guide to Understanding, Sizing, Monitoring, and Managing Consumption of SAP Business Data Cloud Capacity
Units.

## Environment

SAP Business Data Cloud
SAP Analytics Cloud
SAP Datasphere
SAP Databricks

## Resolution

1. What are SAP Business Data Cloud Capacity Units?
A: Refer to SAP Blog SAP Business Data Cloud Capacity Unit Estimator - What are capacity units.
SAP customers purchase a block of CUs for a contract period (e.g. 100 CUs per year).
For more information, refer to the following documents:
SAP Discovery Center – BDC Service Details: SAP Discovery Center - SAP BDC Catalog
SAP Business Data Cloud - FAQs - SAP Community
KBA 3604380 - Allocating Business Data Cloud contract Capacity Units among the available solutions
KBA 3583153 - SAP Datasphere Capacity Unit Consumption
KBA 3616022 - Clarification on Capacity Units for SAP Datasphere Provisioning
2. How many Capacity Units should I assign to my system?
A: Use the tool SAP Business Data Cloud Capacity Unit Estimator to calculate the number of capacity units required for
each SAP BDC capacity service, as well as the total amount needed.
The URL for tool: SAP Business Data Cloud Capacity Unit Estimator. (For SAP Databricks, there is another tool SAP
Databricks Sizing Calculator.)
For more information refer to the following documents:
SAP Business Data Cloud Capacity Unit Estimator
SAP Business Data Cloud Capacity Unit Estimator for SAP Analytics Cloud
SAP Business Data Cloud Capacity Unit Estimator for SAP BDC Connect for Databricks
KBA 3704927 - Clarification on the pricing and consumption model for SAP Databricks within SAP Business Data
Cloud
3. Is there a step by step tutorial on how to add the Capacity Units?
A: Yes, refer to question 3 in KBA 3733691 SAP BDC Onboarding FAQ and video tutorial at SAP Business Data Cloud
Onboarding Webcast (Global) (Go to around 32' of the video). There may be cases where the Total Calculated
Consumption during the provisioning phase exceeds the Total Entitlement. Please note that actual consumption will be
based on your usage patterns rather than the allocated quota. The current Business Data Cloud contract allows Capacity
Units to be freely allocated across available solutions.
4. How to verify Capacity Units consumption?
A: For SAP BDC, the total Capacity Unit consumption can be calculated by summing up the Capacity Unit consumption
of all core component.

In SAP Datasphere, Capacity Unit consumption is shown in the Monitoring - Capacities dashboard and in the
System - Configuration - Tenant Configuration.
In SAC, consumed Capacity Services are shown in System - System Overview dashboard. This usage needs to be
converted to Capacity Units according to sap-business-data-cloud.pdf or SAP Business Data Cloud Supplement.
For SAP Databricks/SAP Business Data Cloud Connect, logon to SAP for Me, navigate to the Finance & Legal
dashboard - Consumption.
To understand further and check the CU consumption for more BDC-related components, refer to the following
documents: sap-business-data-cloud.pdf.
For more information refer to the following documents:
KBA 3650515 - Unexpected over consumption of SAP Business Data Cloud capacity units
KBA 3583153 - SAP Datasphere Capacity Unit Consumption
How to monitor consumption for SAP Business Data C... - SAP Community
Monitoring Capacity Unit Consumption | SAP Help Portal
SAP Business Data Cloud Service Description Guide
SAP Business Data Cloud Supplement
5. How to increase Capacity Units?
A: The current BDC CUs can be allocated among the available solutions.
If there are enough CUs, the increase can be done by editing the provisioned application in SAP For Me. For more
information refer to the following documents:
KBA 3759812 - How to increase the CUs to the provisioned BDC/Datasphere/SAC instance in SAP For Me
KBA 3736776 - How-to increase quota for applications under BDC solution like SAP Datasphere
SAP Help Portal Documentation: Editing Your Provisioned SAP Datasphere Application
If additional Capacity Units are required, contact the Account Executive to request an upsell: KBA 2626344 - Who is the
SAP Account Manager for my company?
For more information refer to the following KBA 3604380 - Allocating SAP Business Data Cloud capacity units among
available solutions.
Note:
BDC licensing queries are not handled by SAP Support.Customer should contact Account Executive for consultation and
avoiding unnecessary delays. To find your Account Executive, refer to KBA 2626344 - Who is the SAP Account Manager for
my company?
