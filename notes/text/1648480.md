# 1648480 – Maintenance for SAP Business Suite 7 Software including SAP NetWeaver

## Symptom

Information on maintenance of SAP Business Suite 7 required

## Other Terms

SAP Business Suite 7, SAP NetWeaver, Java, 7.0x, maintenance, maintenance strategy,
mainstream maintenance, maintenance extension, 2027, 2030.

## Reason and Prerequisites

This note describes details, restrictions and impacts of the mainstream maintenance
extension for SAP Business Suite 7 core applications and corresponding enhancement packages
and add-ons through 2027.

## Solution

In February 2020, SAP announced an extension of the mainstream maintenance for SAP Business
Suite 7 core applications including SAP ERP 6.0, SAP Customer Relationship Management 7.0,
SAP Supply Chain Management 7.0, SAP Supplier Relationship Management 7.0 and corresponding
enhancement packages (*) and add-ons, as well as SAP Business Suite powered by SAP HANA,
from end of December 2025 to end of December 2027. See the SAP Release Brochure
(https://support.sap.com/content/dam/support/en_us/library/ssp/release-upgrademaintenance/maintenance-strategy/sap-release-and-maintenance-strategy-new.pdf) for more
details.
In addition, SAP announced to offer extended maintenance until end of December of 2030.
See SAP note 2881788 (https://launchpad.support.sap.com/#/notes/2881788) for the offered
maintenance phases for Business Suite 7. This gives SAP customers long-term predictability
and planning security.
(*) After 2025, SAP will provide mainstream maintenance for the latest three Enhancement
Packages only.
This note reflects the current status of planning and may be updated at short notice.
Please be aware that SAP Business Suite is based on individual SAP NetWeaver components such
as Application Server ABAP (AS ABAP) and Application Server Java (AS Java).
However, SAP NetWeaver standalone deployments such as SAP Portal, SAP NetWeaver Business
Warehouse and SAP Process Orchestration differ
from SAP Business Suite in some aspects from a maintenance perspective.
Although these products are dedicated applications built on top of the ABAP and Java stacks,
each product can have its own maintenance strategy.
The differences are covered at the end of this SAP note.
Maintenance details for SAP Business Warehouse are covered in SAP note 2741041
(https://launchpad.support.sap.com/#/notes/2741041).

Restrictions
Please note the following restrictions that apply in the context of the mainstream
maintenance extension of SAP Business Suite 7 core applications to 2027:
Application Server ABAP within SAP NetWeaver 7.00, 7.01, 7.02 will be supported in
mainstream maintenance to end of 2025. Extended maintenance will not be offered.
Application Server ABAP within SAP NetWeaver 7.03, 7.31, 7.40 and 7.50 will be supported
in mainstream maintenance to end of 2027. Extended maintenance will be offered until end
of 2030.

Application Server ABAP within SAP NetWeaver 7.10, 7.11, 7.20, 7.30 will be supported in
mainstream maintenance to end of 2020. Extended maintenance will not be offered.
Application Server Java within SAP NetWeaver 7.00, 7.01, 7.02, 7.03 ran out of
mainstream maintenance by the end of 2017. Extended maintenance will not be offered.
Application Server Java within SAP NetWeaver 7.10, 7.11, 7.20, 7.30, 7.31, 7.40 will be
supported in mainstream maintenance to end of 2020. Extended maintenance will not be
offered.
Application Server Java within SAP NetWeaver 7.50 will be supported in mainstream
maintenance to end of 2027. Extended maintenance will be offered until end of 2030.

* SAP NetWeaver 7.03 (SAP NetWeaver 7.0 EHP3) contains the 7.31 ABAP stack, i.e. the same
ABAP stack as SAP NetWeaver 7.3 EHP1, and the 7.02 Java stack, i.e. the same Java stack as
SAP NetWeaver 7.0 EHP2.

The Java stack in SAP NetWeaver 7.00, 7.01, 7.02, 7.03 is based on Java version 1.4.2. This
Java version has reached its end of life and was 15 years old by 2017. SAP has invested
significantly to ensure SAP customers could get support for this version until 2017.
However, these versions are now out of mainstream maintenance.
The Java stack in SAP NetWeaver 7.10, 7.11 is based on Java version 5 (released in 2004);
the Java stack in SAP NetWeaver 7.20, 7.30, 7.31, 7.40 uses Java version 6 (released in
2006). As these Java versions will be very old by 2020, the corresponding Java stacks will
not be supported beyond 2020. Customers should upgrade to SAP NetWeaver 7.5 based on Java
version 8.
The Java stack in SAP NetWeaver 7.50 is based on Java version 8. SAP NetWeaver 7.5 Java will
be supported in mainstream maintenance until end of 2027. Extended maintenance will be
offered until end of 2030.
Java-based applications are dependent on third-party components. To fulfill SAP’s long-term
support commitments, these third-party components have to be supported as well; however the
support cycles offered by the third-party vendors differ from the support timeframes offered
by SAP. SAP has to take these different support cycles into account and therefore is not
free to extend support for Java-based applications by the same timelines as for ABAP-based
applications.

Customers with Java-based SAP NetWeaver 7.0x dual stack systems should plan to split the
dual stack before upgrading.
With SAP NetWeaver 7.5 dual stack deployments are not supported any longer. Since dual stack
deployments are based on both the ABAP stack and the Java stack
the end of maintenace of dual stack deployments is identical to the Java stack. Customers on
older releases should plan for a dual stack split.
More detailed information can be found in
https://help.sap.com/doc/a094d14213b8483d8898605e0c4dc120/1.0%20SP18%20NW7xx%20CORR1/enUS/DSS_7XX_ux.pdf
Please refer also to note 1816819 (Dual Stack Support for Business Suite systems) and
1655335 (Details of dual stack splitting).
Impact
Please note that the following are general guidelines. Exceptions may apply for individual
releases. For information on maintenance for specific releases please refer to the Product
Availability Matrix at http://support.sap.com/pam.
In general the maintenance extension only affects the SAP Business Suite 7 core applications
and their enhancement packages, SAP NetWeaver, and other releases whose maintenance was
aligned with the SAP Business Suite maintenance (that is, releases which had planned
mainstream maintenance to December 2025 in line with the SAP Business Suite 7 core
applications). The maintenance for older releases, and releases which were not aligned with
the SAP Business Suite 7 maintenance phases, remains unchanged.
Core applications of SAP Business Suite 7
Mainstream maintenance for SAP ERP 6.0, SAP CRM 7.0, SAP SCM 7.0, SAP SRM 7.0, and
enhancement packages to these releases will be extended through December 2027. Please note
that the restrictions in support for Java-based applications may affect these applications
to such a degree as they contain, work with or form the basis of Java-based content or
applications (also see below under "SAP NetWeaver Application Server Java").
ABAP add-ons, other ABAP-based standalone releases
For ABAP-based add-on applications to the core application releases, to their enhancement
packages, or to SAP NetWeaver, as well as for other ABAP-based releases, SAP will decide on
a case-by-case basis whether existing releases of these applications will follow the longer
mainstream maintenance to 2027 or whether SAP will ship new releases in a so-called add-on
release sequence.
SAP Gateway add-ons
The add-ons of SAP Gateway 2.0 are installed on various SAP NetWeaver Releases. The add-ons
of SAP Gateway will follow the longer mainstream maintenance to 2027 if the same is offered
for the underlying SAP NetWeaver Release on which they are installed. This means for example
that the maintenance of GW_CORE and IW_FND ends December 2025 if being installed on top of
SAP NetWeaver 7.02 whereas maintenance will be offered through December 2027 if both add-ons
would run on top of SAP NetWeaver 7.31.

Java add-ons, other Java-based standalone releases and content
Standalone and add-on applications as well as content based on or working with the Java
stack within SAP NetWeaver 7.00, 7.01, 7.02, 7.03 ran out of mainstream maintenance by
the end of 2017.
Standalone and add-on applications as well as content based on or working with the Java
stack within SAP NetWeaver 7.10, 7.11, 7.20, 7.30, 7.31, 7.40 will be supported to 2020.
Please note that applications may also offer a release sequence, meaning that the
timeframe to 2020 may be filled by more than one release based on e.g. SAP NetWeaver
7.30 Java.
Standalone and add-on applications as well as content based on or working with the Java
stack within SAP NetWeaver 7.50 will be supported in mainstream maintenance to 2027.
Please note that applications may also offer a release sequence, meaning that the
timeframe to 2027 may be filled by more than one release based on SAP NetWeaver 7.50
Java.
Remark
Application Server Java 7.5 for SAP S/4HANA is supported in mainstream maintenance until
end of 2030.
Please note that AS Java for SAP S/4HANA is only supported on SAP databases (SAP HANA, SAP
ASE, MAXDB) as documented in the Product Availability Matrix (PAM).
Additional information
Thís note describes the maintenance strategy for the SAP Business Suite and therefore also
covers components of SAP NetWeaver that are required to run the SAP Business Suite
such as SAP NetWeaver Application Server ABAP (AS ABAP) and SAP NetWeaver Application Server
Java (AS Java).
SAP NetWeaver standalone hub deployments such as SAP Portal, SAP Business Warehouse, SAP
Process Integration etc have their own maintenance strategy. The PAM documents the
availability
of SAP NetWeaver in total. Tools such as EWA reporting pick the availability dates from the
PAM but cannot reflect the content of this note entirely.
