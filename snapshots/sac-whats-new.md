### 2025-05-17 · Ability to Save and Pin Data Analyzer Insights to Story in View Mode

*Action: Info only · Area: General · Component: SAP Analytics Cloud · Environment: Cloud Foundry · Software_Lifecycle: General Availability · Type: New · Version: Q2 2025 (2025.2 - 2025.8) · SAP-ID 590040691*

Starting from a story in view mode, you can now create an (data analyzer) insight and pin it to the story visualization for personal quick access. For this, simply open data analyzer from the standard context menu Open Data Analyzer in your story visualization, explore the data in data analyzer and save and pin the insight to the story visualization. You can repeat this procedure according to your business needs; there is no limitation on the number of pinned insights to a story visualization. The pinned insights are listed in an ascending order from newest to oldest under the Open Data Analyzer context menu entry.  

### 2025-02-15 · Introducing <span class="ph pname">SAP Analytics Cloud</span> Compass

*Action: Info only · Area: Compass · Component: SAP Analytics Cloud · Environment: Cloud Foundry · Software_Lifecycle: General Availability · Type: Announcement · Version: Q1 2025 (2024.22 - 2025.1) · SAP-ID 590040833*

You can now use SAP Analytics Cloud compass, a new app that allows you estimate the possible outcomes of uncertain business events using Monte Carlo simulation. By gaining insights into the range of potential outcomes and the probabilities of achieving them, it empowers you to make more informed business decisions in the face of uncertainty. Best of all, you can achieve this without the need for prior IT setup or advanced statistical skills.  
In compass, you can do the following:  
- Create simulations with scenario modelling capabilities: To address your business question, create a simulation from a table data cell or the compass start page. Within the simulation, you can create scenarios to simulate the impact of driver assumptions on the target values. The simulation can be saved as a file repository artifact and shared with others.  
- Configure drivers in private scenarios: In a private scenario, select from available drivers and configure drivers by setting their input filters and randomness. In particular, you can set value ranges and probability distribution types to specify driver randomness.  
- Add and configure restricted drivers: Add restricted drivers from a base driver by configuring their specific filters, and set value ranges and probability distribution types to specify randomness on restricted drivers.  
- Run private scenarios: Run private scenarios in different precision modes and get simulation results visualized by a graph for each run.  
- Analyze simulation results: Based on the simulation result graph, analyze the probability distribution of the simulated outcomes. You can also move the slider to explore chances of achieving below or above a specific target value. Additional operations, such as defining case settings and adding comparison scenarios, provide further insights into the simulation results.  
- Create public scenarios: Publish private scenarios to create public scenarios, making them available to all users with access to the simulation.
