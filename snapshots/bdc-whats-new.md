### 2026-10-30 · Integration with SAP Revenue Growth Management

*Area: Data Integration · Action: Info only · Type: New · Software_Lifecycle: General Availability · Environment: Cloud Foundry · Component: SAP Business Data Cloud · SAP-ID 596844529*

SAP Revenue Growth Management is a cloud-native solution that supports key revenue growth activities, including key account management, promotion planning, and so on.  
You can now integrate an instance of SAP Revenue Growth Management with your SAP Business Data Cloud landscape as a data product consumer and provider.

### 2026-10-22 · <span class="ph pname" translate="no">SAP S/4HANA Cloud Private Edition</span> Support for Incremental Data Product Extensions

### 2026-10-20 · System Mappings for Content Transport Between <span class="ph pname" translate="no">SAP Datasphere</span> Tenants

*Area: Administration · Action: Info only · Type: New · Software_Lifecycle: General Availability · Environment: Cloud Foundry · Component: SAP Business Data Cloud · SAP-ID 596844469*

You can now configure system mappings in SAP Business Data Cloud to pair source and target data-product provider system instances. When an SAP Datasphere user transports a package from one tenant to another, the target space automatically connects to the correct data-product provider system based on the configured mapping, removing the need for manual reconnection after import.  
Optionally, you can specify a target space ID to control which space in the destination tenant receives the imported content.  
For more information, see [System Mapping for Content Transport Between SAP Datasphere Tenants](4a4024c409ef427ebe285b8e60a9e58a.html).

### 2026-03-03 · Share Data Products to <span class="ph pname" translate="no">SAP Datasphere</span>, Data Composer

*Area: Data Cataloging · Action: Info only · Type: New · Software_Lifecycle: General Availability · Environment: Cloud Foundry · Component: SAP Business Data Cloud · SAP-ID 596844509*

SAP Datasphere, Data Composer is a service available within SAP Business Data Cloud. It harmonizes and unifies customer data from multiple available data products. The composer consolidates disparate records into comprehensive customer profiles by using configurable unification rules and advanced identity resolution.  
Users can choose between deterministic models, which use rule-based and exact matching, or probabilistic models, which use machine learning for flexible matching. These models help resolve identities, handle data conflicts, and merge records based on data quality, ingestion timestamp, and rule priority. The composer also supports mapping and transforming source data attributes to a fixed output schema. This ensures data normalization and quality.  
The harmonized profiles are output as a data product called Potential Customer Profile. Other systems can then consume this data product.  
The data composer helps organizations create a single, trusted view of customers by integrating fragmented data from different business units and systems. This improves data quality, supports compliance, and enhances customer insights for analytics, personalization, and operational efficiency. By automating identity resolution and profile unification, the composer reduces manual data reconciliation, accelerates time-to-value, and supports scalable, secure data management in complex enterprise environments.  
For more information, see [SAP Datasphere, Data Composer](15139eeaa2a440d1a8f0a46fd79d2bd7.html).

### 2025-07-22 · Improved Share Status Monitoring for Data Products Shared to Target Systems

*Area: Data Cataloging · Action: Info only · Type: New · Software_Lifecycle: General Availability · Environment: Cloud Foundry · Component: SAP Business Data Cloud · Version: 1.0 · SAP-ID 596844525*

The share status for data products will be monitored for changes on the target system every 24 hours and updated in the catalog as needed:  
- If the data product share is deleted from the target system, the data product's share status is updated to Shareable.  
- If the data product's current share status is In Progress for longer than one hour, but the data product was not shared to the target system, the share status is updated to Shareable.  
- When the data product is shared with the target system and the share status has been In Progress for more than an hour, it is changed to Shared.
