System Mappings for Content Transport Between SAP Datasphere Tenants

You can now configure system mappings in SAP Business Data Cloud to pair source and target data-product provider system instances. When an SAP Datasphere user transports a package from one tenant to another, the target space automatically connects to the correct data-product provider system based on the configured mapping, removing the need for manual reconnection after import.

Optionally, you can specify a target space ID to control which space in the destination tenant receives the imported content.

For more information, see System Mapping for Content Transport Between SAP Datasphere Tenants.

Data Product Governance Improvements
Changes to data product governance provide a better framework for domain management, access control, and usage agreements:
  • Domains: Organizations can define clear ownership of data products and set the terms and conditions for their usage (see Governing Data Products).
  • Access workflows: Data stewards have more control over who can access data products. Rather than relying on direct permissions and manual sharing, data product access shifts to a request-based model. These controlled workflows ensure compliance and traceability of data product consumption across the landscape (see Obtaining Access to Data Products).

For more information about data governance, read the blog: Data Product Data Governance in SAP Business Data Cloud.
